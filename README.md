## 🧩 Project Overview

### 01 – Linux Basics
Linux fundamentals: shell, permissions, processes, and system concepts.  
[Explore this module](./01-linux-basics/README.md)

### 02 – Secure Embedded Authentication ✅
Secure authentication module written in C for embedded Linux systems:  
- no plain-text password in the binary  
- hash-based verification (djb2)  
- cross-compilation for x86 and ARM (Raspberry Pi)  
[Explore this module](./02-secure-authentication/README.md)

### 03 – Raspberry Pi Bring-up ✅
- headless OS installation  
- SSH setup  
- System update and verification
[Explore this module](./03-raspberrypi-bringup/README.md)

### 04 – Embedded Networking (planned)

### 05 – Build Systems (target 2026)
